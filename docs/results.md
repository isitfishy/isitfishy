# Results

Headline rates of the scoring service behind the public app. How the samples were chosen
and measured is kept private so it cannot be used to evade detection.

| Sample | Result |
| --- | --- |
| Recent scam links, first sample (143) | 75.5% flagged |
| Recent scam links, second sample (301) | 35.9% flagged |
| Ordinary sites (400) | 1 flagged |

The samples are small and differ from each other, so the two scam rates are not comparable.
The stub scorer in this repository does not judge anything and does not produce these
results.
